# Fe2-O3 Homebrew Tap

Homebrew formulae for [Fe2-O3](https://github.com/Fe2-O3) projects.

## Install

```bash
brew tap Fe2-O3/tap
brew install --cask humdrop
```

## Available Casks

| Cask | Description |
|------|-------------|
| `humdrop` | Sync 4K video and photos from WiFi bird and trail cameras |
